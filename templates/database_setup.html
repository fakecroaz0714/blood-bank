DATABASE SETUP REQUIRED

Persistent database not connected

Vercel’s app filesystem is read-only and its SQLite file cannot store live blood bank updates. Connect a managed PostgreSQL database to the Vercel project to enable inventory and other data changes.

  1. Add DATABASE_URL or POSTGRES_URL in Vercel Project Settings → Environment Variables.
  2. Use the connection string for your Supabase or Vercel Postgres database, with a password URL-encoded if needed.
  3. Redeploy. The app will create the additive blood bank tables on its first request.
